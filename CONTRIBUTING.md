# Contributing

Contributions should preserve the project’s evidence boundaries.

1. Open an issue describing the methodological or product change.
2. Add or update tests.
3. Run `ruff check .` and `pytest`.
4. Run `npm run lint` and `npm run build` in `frontend`.
5. Document any new data source, license, transformation, and known limitation.

Do not commit API keys, raw restricted job postings, proprietary datasets, or imputed
values presented as published statistics.
